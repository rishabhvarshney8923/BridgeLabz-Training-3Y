ASSIGNMENT 1 – Web Development Fundamentals
1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.

Frontend Development

Frontend development is the part of web development that focuses on what users see and interact with on a website. It includes designing the layout, navigation menus, buttons, forms, images, and animations. Frontend developers mainly use HTML, CSS, and JavaScript along with frameworks such as React or Angular.

Backend Development

Backend development focuses on the server-side of a website. It handles business logic, user authentication, databases, APIs, and server communication. Backend developers commonly use programming languages such as Python, Java, PHP, and JavaScript (Node.js) along with databases like MySQL or MongoDB.

Full-Stack Development

Full-stack development combines both frontend and backend development. A full-stack developer is capable of building complete web applications, including the user interface, server logic, database, and APIs.

Real-World Example (Amazon):

The product listings, shopping cart, search bar, and buttons are part of the frontend.
User login, payment processing, inventory management, and order tracking are handled by the backend.
A full-stack developer can work on both the frontend and backend components of the website.

3. Describe how a browser requests and displays a web page from a web server.

When a user enters a website address (URL) into a web browser, the browser sends an HTTP or HTTPS request to the web server. The server receives the request and processes it. If the webpage requires data, the server retrieves it from a database. The server then generates the webpage and sends it back to the browser. The browser downloads the HTML, CSS, JavaScript, images, and other resources, interprets them, and renders the webpage on the user's screen. Finally, JavaScript executes to make the webpage interactive.

4. Identify and list the tools required to set up a web development environment. Explain the purpose of each.

Visual Studio Code (VS Code): A lightweight source code editor used to write and edit HTML, CSS, JavaScript, and other programming languages.

Google Chrome or Microsoft Edge: Modern web browsers used to test websites and access built-in Developer Tools for debugging.

Live Server Extension: A VS Code extension that automatically refreshes the webpage whenever changes are made to the source code.

Node.js: A JavaScript runtime that allows JavaScript to run outside the browser and is required for many frontend and backend development tools.

Git: A version control system used to track changes in source code and collaborate with other developers.

GitHub: An online platform used to host Git repositories, collaborate on projects, and manage source code.

Terminal or Command Prompt: Used to execute commands, install packages, run applications, and manage files.

Browser Developer Tools: Built-in browser tools that help developers inspect HTML, CSS, JavaScript, network requests, and website performance.

5. Explain what a web server is and give examples of commonly used servers.

A web server is software or hardware that receives requests from web browsers, processes those requests, and sends web pages or other resources back to users using the HTTP or HTTPS protocol.

Commonly used web servers include:

Apache HTTP Server
Nginx
Microsoft Internet Information Services (IIS)
Node.js with Express.js
LiteSpeed

For example, when a user visits Amazon.com, the browser sends a request to Amazon's web server. The server processes the request, retrieves the required information, and sends the webpage back to the browser.

6. Define the roles of a frontend developer, backend developer, and database administrator in a project.

Frontend Developer

A frontend developer designs and develops the user interface of a website. Their responsibilities include creating responsive layouts, improving user experience, implementing interactive features, and ensuring compatibility across different browsers and devices.

Backend Developer

A backend developer develops the server-side logic of a web application. They create APIs, handle authentication and authorization, connect applications with databases, and ensure secure and efficient processing of user requests.

Database Administrator (DBA)

A database administrator is responsible for designing, managing, securing, and maintaining databases. They ensure data integrity, perform backups, optimize database performance, and protect data from unauthorized access.

8. Explain the difference between static and dynamic websites. Provide an example of each.

A static website displays the same content to every visitor. The content is fixed and only changes when the developer manually edits the source code. Static websites are generally built using HTML and CSS.

Examples: Personal portfolio websites, company profile websites, landing pages.

A dynamic website generates content based on user interactions or data stored in a database. These websites use server-side programming languages and databases to provide personalized and interactive experiences.

Examples: Amazon, Facebook, Instagram, Gmail, YouTube.

9. Research and list five web browsers. Explain how rendering engines differ between them.

Five commonly used web browsers are:

Google Chrome
Microsoft Edge
Mozilla Firefox
Apple Safari
Opera

Rendering engines used by these browsers are:

Google Chrome uses the Blink rendering engine.
Microsoft Edge uses the Blink rendering engine.
Mozilla Firefox uses the Gecko rendering engine.
Apple Safari uses the WebKit rendering engine.
Opera uses the Blink rendering engine.

A rendering engine is responsible for converting HTML, CSS, and JavaScript into the visual webpage displayed on the screen. Different rendering engines implement web standards differently, which may result in slight differences in how websites appear or function across browsers.
